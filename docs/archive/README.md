# Archive

Retired page content, kept for reference. Nothing in here is built — Astro's project
collection only globs `src/content/projects/`, so these files never ship.

## `6dof-robotic-arm.md`

The original 6-DOF robotic arm write-up, as of commit `e185359` (2026-09-28), archived
when I restarted that page from scratch.

Most of it was scaffolding I never replaced: large commented-out blocks of placeholder
`code_files`, `components`, performance tables, and analysis plots, plus Lessons Learned
and Future Enhancements sections quoting accuracy and cycle-time numbers I never measured.
The parts I actually wrote are the Project Overview and the Key Features list (AR4 MK5,
ROS2 Jazzy, Gazebo).

The referenced assets are still in `public/assets/` — `images/projects/robotic-arm/featured.jpg`,
`models/robotic-arm/*.gltf`, `schematics/robotic-arm/*.svg`. They're placeholder artifacts,
not renders or schematics of the real arm.
